The most useful AI tools shipping right now aren't models. They're the infrastructure around models.

I watch GitHub trending the way some people watch earnings calls — it tells you where the real leverage is moving, not where the marketing budget is going.

This week's list makes the pattern obvious:

- **alibaba/open-code-review** — a hybrid code review tool battle-tested at Alibaba's scale. Deterministic rulesets (NPE, thread-safety, XSS, SQL injection) catch what rules are good at catching. An LLM agent catches what needs judgment. It doesn't ask a model to do a linter's job.
- **citrolabs/ego-lite** — lets Codex or Claude Code share your logged-in browser state instead of re-authenticating and re-discovering context every session. Small idea, real time saved on every run.
- **pbakaus/impeccable** — a design language purpose-built for how models reason about layout, so your AI harness stops guessing at spacing and produces usable UI on the first pass.
- **virgiliojr94/book-to-skill** — turns a technical book PDF into a loadable Claude Code skill instead of a wall of context you paste in every session.

None of these are frontier models. All four are harnesses, adapters, and infrastructure that make the model you already have more useful.

That's the real story of 2026's AI tooling wave: the moat isn't picking the smartest model. It's who builds the best scaffolding around whatever model wins this quarter.

If your AI strategy is "wait for the next model release," you're optimizing the wrong variable. The teams shipping real ROI right now are the ones investing in harnesses, not chasing benchmarks.
