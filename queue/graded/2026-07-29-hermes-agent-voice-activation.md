Hermes Agent just shipped voice activation — wake word, hands-free, local detection, off by default.

"Hey Hermes" starts a new session in the CLI, TUI, or desktop app. It can even pick up profile names. The ear icon in the GUI toggles it. Detection runs locally, not in the cloud.

This is the open-source agent I actually run on my local hardware. Voice is the UX shift that turns an agent from a tool you talk at into something you talk to — and the "off by default, local detection" choice is exactly how this should ship. No cloud wake word. No always-on microphone. You opt in.

The gap between "AI assistant" and "AI operator" keeps narrowing. Hermes just closed it a little more.
